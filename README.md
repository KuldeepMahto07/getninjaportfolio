# Rohit Sharma — Portfolio

A single-page portfolio for **Rohit Sharma**, Generative AI Developer.

Built as a single self-contained `index.html` file: vanilla JS, CSS variables for theming, a dark minimal theme, scroll-triggered fade-ins, scrolling skill marquees, a live local-time (IST) footer clock, and a working `mailto:` contact link. Fully responsive and respects `prefers-reduced-motion`.

## Sections
- Fixed nav with availability badge
- Hero with headline + CTA
- What I Do — three numbered service blocks
- Selected Works — Yummi, Deblo
- Skills — scrolling marquees
- About
- Contact CTA
- Footer with live local time

## Run locally
Just open `index.html` in a browser — no build step required.

```bash
# or serve it
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (GitHub Pages)
Settings → Pages → deploy from branch → `main` / root. It will be live at `https://kuldeepmahto07.github.io/getninjaportfolio/`.
